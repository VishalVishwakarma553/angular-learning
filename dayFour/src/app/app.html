Day 4 Architectural Concepts Mastered

1. NonNullableFormBuilder

fb = inject(NonNullableFormBuilder)

Eliminates unwanted null types. When .reset() is called, controls revert to their initial typed values instead of null!

2. Custom Async Validator

usernameAvailabilityValidator()

Simulates real-world API latency with timer(600) and triggers the PENDING status while validating against a remote database.

3. Cross-Field Validator

passwordMatchValidator

Attached to the parent FormGroup to compare multiple sibling fields together (password === confirmPassword).

4. FormArray & toSignal()

skills: fb.array<FormGroup>([]) toSignal(form.valueChanges)

Dynamic row addition/deletion, plus instantaneous projection of form streams directly into Angular Signals!
