Day 3 Architectural Takeaways: Clean Angular Best Practices

1. Functional inject() vs Constructor

private cartService = inject(CartService);

Eliminates verbose constructor injection, works seamlessly in inheritance, and allows injecting tokens and DestroyRef anywhere.

2. State Encapsulation with asReadonly()

#items = signal<CartItem[]>([]) readonly items = this.#items.asReadonly()

Components can safely react to state without being able to arbitrarily mutate internal store arrays directly.

3. DestroyRef for Automatic Cleanup

destroyRef = inject(DestroyRef); this.destroyRef.onDestroy(() => ...)

Replaces boilerplate ngOnDestroy hooks and manual Subject takeUntil pipes with native lifecycle tear-down.
